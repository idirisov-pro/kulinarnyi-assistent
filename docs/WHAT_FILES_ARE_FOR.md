# Для чего нужны файлы

## Файлы, необходимые для работы приложения

| Файл | Назначение |
|---|---|
| `index.html` | Структура экранов и элементов интерфейса. |
| `styles.css` | Внешний вид, размеры, мобильная адаптация и состояния элементов. |
| `app.js` | Подбор рецептов, переходы между экранами, таймер, избранное и WhatsApp-отчёт. |
| `data/ingredients.js` | Справочник продуктов, категории, варианты названий и базовые продукты. |
| `data/recipes.js` | Рецепты, количества, роли ингредиентов, замены и шаги. |

## Файлы для PWA и локального запуска

| Файл | Назначение |
|---|---|
| `manifest.webmanifest` | Позволяет установить приложение на экран телефона. |
| `service-worker.js` | Сохраняет файлы в кэше и даёт базовую работу без интернета. |
| `icons/` | Иконки установленного приложения. |
| `start_local.bat` | Запускает локальный сервер на Windows. Удобство, а не логика продукта. |

## Вспомогательные файлы

| Файл | Назначение |
|---|---|
| `README.md` | Краткая инструкция. На работу приложения не влияет. |
| `scripts/validate-data.js` | Ищет ошибки в рецептах и справочнике продуктов. |
| `docs/` | Аудит и правила работы. Пользователю приложения не показываются. |
