# Объём первого дня

## Входит

- одна органическая публикация или Story/статус;
- несколько точечных личных приглашений к тесту;
- одна тематическая публикация только при разрешении правилами сообщества;
- фиксация реальных прохождений и повторяющихся проблем.

## Не входит

- любая платная реклама;
- покупка охвата, кликов, подписчиков или отзывов;
- массовые рассылки незнакомым людям;
- одновременный спам одинаковой ссылкой по множеству групп;
- выводы о спросе только по просмотрам или лайкам.

## Результат дня

Набор первых реальных пользовательских сигналов, достаточный для решения: продолжать распространение, сначала исправить продукт или уточнить сценарий тестирования.
