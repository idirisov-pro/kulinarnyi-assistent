# P0: следующий технический шаг

1. Создать отдельную ветку от актуальной `main`.
2. Добавить независимый клиентский модуль регистрации событий.
3. Подключить его к ключевым продуктовым действиям.
4. По умолчанию хранить события локально и не отправлять их наружу до выбора проверенного центрального приёмника.
5. Добавить механизм безопасной очереди для последующей сетевой отправки.
6. Не изменять публичную `main` до ручной проверки.
7. После выбора центрального приёмника подключить тестовую отправку и только тогда считать P0-A/P0-B технически реализованными.
