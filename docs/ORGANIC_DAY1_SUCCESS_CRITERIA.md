# Критерии успеха первого дня

Первый день считается полезным, если получен хотя бы один из следующих типов сигнала:

- несколько независимых пользователей прошли основной сценарий до открытия рецепта;
- получены конкретные замечания, которые можно воспроизвести;
- выявлена повторяющаяся блокирующая проблема;
- обнаружен устойчивый запрос на отсутствующий продукт, рецепт или функцию;
- пользователи самостоятельно пересылают ссылку другому человеку.

## Что не считается успехом само по себе

- просмотры публикации;
- лайки;
- реакции без прохождения продукта;
- рост числа подписчиков;
- положительные комментарии без конкретного опыта использования.

Цель первого дня — получить материал для следующего продуктового решения, а не создать видимость большого охвата.
