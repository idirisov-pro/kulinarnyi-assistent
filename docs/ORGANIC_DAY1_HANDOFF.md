# Передача на ручное размещение — День 1

Все подготовительные действия, которые можно выполнить в репозитории без доступа к личным аккаунтам социальных сетей, завершены.

## Что уже готово

- бесплатная публичная версия приложения;
- бюджет привлечения 0 сомов;
- отдельные UTM-ссылки для бесплатных каналов;
- готовые тексты для Instagram, WhatsApp, Telegram и продуктовых сообществ;
- порядок первого дня;
- критерии остановки;
- журнал фактических результатов.

## Единственные действия, требующие владельца аккаунта

1. Опубликовать подготовленный материал в выбранном собственном бесплатном канале.
2. Использовать ссылку именно этого канала.
3. После первых прохождений фиксировать только реальные замечания пользователей.

До отдельного решения платное продвижение не используется.
