# Проверка каждого рецепта перед рассылкой

- [ ] Название ингредиента однозначно: указаны вид мяса, вид фарша и состояние продукта.
- [ ] Все основные ингредиенты имеют точные количества.
- [ ] Вода, масло, соль и специи указаны явно.
- [ ] Ингредиенты разделены на критические, обязательные, рекомендуемые и базовые.
- [ ] Каждая замена относится к ингредиенту, который действительно есть в рецепте.
- [ ] Замена не нарушает технологию и безопасность.
- [ ] Количество рассчитано для базового числа порций.
- [ ] Общее время реалистично.
- [ ] Каждый шаг можно понять без дополнительных догадок.
- [ ] Указаны признаки готовности сырого мяса, птицы или яиц.
- [ ] Рецепт фактически приготовлен минимум один раз.
- [ ] Замечания после приготовления внесены в данные.
