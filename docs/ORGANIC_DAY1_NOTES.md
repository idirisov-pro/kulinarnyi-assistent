# Примечание к запуску

Этот пакет не запускает публикации автоматически: размещение в социальных сетях и мессенджерах требует доступа к соответствующим пользовательским аккаунтам.

Все действия внутри проекта, которые можно выполнить без такого доступа, подготовлены: ссылки, тексты, порядок действий, критерии качества и правила остановки.

До отдельного решения расход на привлечение остаётся равным **0 сомов**.
