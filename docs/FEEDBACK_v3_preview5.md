# Кулинарный ассистент — feedback → 3.0-preview.5

Дата фиксации: 2026-08-16

## Полученные отзывы

### Отзыв 1

- приложение стало удобнее;
- пользователь хотел установить 14 порций, но увидел 20;
- количество предложенных блюд показалось недостаточным;
- остальные сценарии оценены как удобные.

### Отзыв 2

- версия стала лучше;
- поиск воспринимается как требующий полного ввода названия;
- ввод первых букв и нажатие клавиши поиска/Enter не приводили к ожидаемому выбору продукта.

## Результаты полного check-up

1. **Ручной ввод порций был уязвим для мобильного сценария.** Поле синхронизировалось и переписывалось на каждом событии `input`. Это могло мешать последовательному набору двух цифр или молча ограничивать случайно полученное значение числом 20.
2. **Поиск технически использовал подстроку, но UX был неоднозначным.** Запрос `кар` одновременно находил `Картофель` и `Макароны`; Enter отправлял всю форму вместо выбора найденного продукта.
3. **Выдача искусственно ограничивалась тремя точными рецептами.** Даже при большом количестве совпадений пользователь видел максимум три подходящих и два близких варианта.
4. **Строгий режим противоречил своему описанию.** В блоке близких вариантов могли появляться рецепты с обязательной докупкой.
5. **Текст количества продуктов не склонялся.** Отображалось `1 продуктов`.
6. **Cache-first Service Worker мог удерживать предыдущую сборку**, особенно у участников повторного тестирования.
7. Структура данных, ссылки ингредиентов, статусы 23 рецептов, пересчёт количеств, навигация, история, избранное и базовая мобильная вёрстка прошли повторную проверку. Кулинарная достоверность 13 рецептов со статусом `draft` по-прежнему требует фактического приготовления и не повышалась автоматически.

## Исправления 3.0-preview.5

- prefix-first поиск с нормализацией `ё/е` и поддержкой синонимов;
- исключение нерелевантных подстрочных совпадений, если есть совпадения по началу слова;
- Enter и кнопка `Добавить` выбирают единственный найденный продукт;
- неоднозначный запрос показывает количество вариантов и предлагает выбрать конкретный продукт;
- ручное поле порций больше не переписывается после каждой введённой цифры;
- подтверждение значения выполняется по `change`, потере фокуса или Enter;
- добавлены кнопки `−` и `+`, выделение содержимого при фокусе и явное сообщение о диапазоне 1–20;
- снято ограничение в три точных результата;
- сначала показываются шесть лучших рецептов, остальные раскрываются кнопкой `Показать ещё`;
- число точных и близких вариантов выводится в контексте результата;
- строгий режим не показывает близкие рецепты, требующие обязательной докупки;
- исправлено склонение `1 продукт / 2 продукта / 5 продуктов`;
- добавлены быстрые действия при пустой выдаче;
- Service Worker переведён на network-first и версионные URL ресурсов;
- обновлены CI-проверки, README и сценарий внешнего тестирования.

## Зафиксированное ограничение

База по-прежнему содержит 23 рецепта. Preview.5 устраняет искусственное сокращение выдачи, но не подменяет расширение и фактическую кулинарную проверку контента.
