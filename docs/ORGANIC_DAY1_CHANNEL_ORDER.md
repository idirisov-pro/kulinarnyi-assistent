# Порядок бесплатных каналов — День 1

## Приоритет

1. **Собственный органический канал** — обычная публикация/Story/статус без продвижения.
2. **Личные сообщения в WhatsApp** — только нескольким релевантным людям, которые действительно готовят дома.
3. **Telegram-сообщество** — только если правила разрешают самопрезентацию и прямые ссылки.
4. **Reddit/продуктовые сообщества** — не использовать как массовый первый канал; перед публикацией проверить правила и историю участия аккаунта.

## Почему Reddit не ставим первым

Актуальные правила и практика Reddit требуют учитывать правила каждого сообщества и избегать аккаунта, который используется почти только для самопродвижения. Поэтому Reddit применяем как канал содержательной обратной связи, а не как бесплатный аналог рекламной сети.

## Главное ограничение

Не публиковать одинаковый рекламный текст одновременно в большом числе сообществ. Цель — получить проверяемый пользовательский сигнал, а не максимальное количество ссылок в интернете.
