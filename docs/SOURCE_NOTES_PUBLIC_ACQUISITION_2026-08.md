# Источники для решения по первому платному каналу

Дата проверки: 2026-08-27.

## Instagram / Meta

DataReportal, `Digital 2026: Kyrgyzstan`: опубликованные данные рекламных инструментов Meta оценивали аудиторию Instagram в Кыргызстане в 3,90 млн пользователей в конце 2025 года; охват среди взрослых 18+ — около 78,7%.

Вывод для проекта: Instagram достаточно велик для локального пятидневного теста и не требует распылять небольшой бюджет между каналами.

## Google Ads

Google Ads Help: Кыргызстан присутствует в региональной таблице условий сервиса; в перечне стран/территорий, где Google Ads недоступен из-за санкционных ограничений, Кыргызстан не указан.

Вывод для проекта: Google Search можно использовать как вторую волну по высокоинтентным поисковым запросам после первой проверки продукта.

## Telegram Ads

Материалы 2026 года показывают заметную вариативность условий доступа и практических минимальных бюджетов между типами кабинетов и посредниками. 26 августа 2026 года отраслевые публикации также сообщали об изменении минимальных CPM для ряда стран СНГ, включая Кыргызстан.

Вывод для проекта: не использовать Telegram Ads первым при бюджете всего 1 500 сомов; канал можно вернуться тестировать после появления подтверждённой пользовательской ценности.

## Принцип использования источников

Числа из рекламных платформ и отраслевых публикаций не считаются гарантией результата. Они используются только для выбора первого канала. Реальное решение о масштабировании принимается по данным собственного пилота.
