# P0: карта точек регистрации событий

Дата: 2026-09-04
Статус: предварительная карта перед изменением кода

## Цель

Перед внедрением аналитики зафиксировать, в каких местах продуктовой логики должны возникать события. Это снижает риск дублирования, пропусков и зависимости аналитики от интерфейсных деталей.

## События и смысл

| Событие | Когда фиксировать | Что не считать событием |
|---|---|---|
| Начало сеанса | После успешной инициализации приложения | Простую загрузку отдельного статического ресурса |
| Добавление продукта | После фактического изменения набора выбранных продуктов | Клик по уже выбранному продукту без изменения состояния |
| Удаление продукта | После фактического удаления из набора | Наведение/фокус |
| Запуск подбора | После прохождения проверки формы непосредственно перед расчётом результатов | Нажатие, если форма невалидна и подбор не выполняется |
| Показ результатов | После сформированной выдачи | Переход на экран результатов без пересчёта |
| Отсутствие результатов | Когда после подбора нет точных результатов; отдельно сохранить число близких вариантов | Случай, когда точные результаты есть |
| Открытие рецепта | После открытия конкретной карточки рецепта | Прокрутку списка результатов |
| Начало приготовления | После явного действия пользователя «Начать готовить» | Простое открытие рецепта |
| Завершение приготовления | После явного действия пользователя о завершении | Истечение таймера само по себе |
| Отправка отзыва | Только после подтверждённого успешного сохранения на центральном сервере | Копирование текста в буфер или неудачную сетевую попытку |
| Повторный визит | Новый сеанс на уже известной установке/браузере | Перезагрузку в рамках того же активного сеанса, если она не соответствует принятому правилу новой сессии |

## Требование к внедрению

События должны вызываться из продуктовой логики, а не отслеживаться по CSS-селекторам или внешнему перехвату кликов. Это уменьшает вероятность ложных событий после изменения интерфейса.

Точная привязка к функциям `app.js` должна быть проверена непосредственно перед изменением кода по актуальной версии ветки, а не перенесена из старых снимков.
