# Пакет публичного запуска

Основные документы:

- `PUBLIC_ACQUISITION_PILOT_2026-08.md` — стратегия первой бесплатной органической волны;
- `AD_PLATFORM_SETUP_NOTES.md` — рабочие заметки по бесплатному распространению и готовые ссылки/тексты;
- `ORGANIC_PILOT_READINESS_CHECKLIST.md` — контроль перед бесплатным запуском;
- `ORGANIC_PILOT_METRICS_TEMPLATE.md` — фиксация результатов по дням без финансовых показателей;
- `LAUNCH_DECISION_LOG_2026-08-27.md` — зафиксированное решение о бюджете 0 сомов и ограничения;
- `SOURCE_NOTES_PUBLIC_ACQUISITION_2026-08.md` — принципы бесплатного привлечения.

Публичные страницы продукта:

- `/privacy.html` — конфиденциальность;
- `/terms.html` — условия использования.

Автоматическая проверка пакета: `node scripts/check-public-launch.mjs`.

## Финансовое ограничение

До отдельного нового решения владельца проекта расход на привлечение пользователей равен **0 сомов**. Платная реклама, платные размещения, платные блогеры и покупка трафика не являются частью текущего запуска.
