- `PAID_PILOT_METRICS_TEMPLATE.md` — фиксация результатов по дням;
- `LAUNCH_DECISION_LOG_2026-08-27.md` — зафиксированное решение и ограничения;

Публичные страницы продукта:

- `/privacy.html` — конфиденциальность;
