# Кулинарный ассистент — версия 3.0-preview.5

Пятый рабочий инкремент версии 3.0. Это статическое PWA без сервера, регистрации, платных API и внешней базы данных.

## Открыть приложение

**Актуальная публичная версия:** https://idirisov-pro.github.io/kulinarnyi-assistent/

Приложение публикуется через GitHub Pages из ветки `main` этого репозитория.

## Что сохранено

- выбор продуктов из нескольких категорий;
- «Моя кухня» с локальным сохранением выбранных, исключённых и базовых продуктов;
- режимы «Только из выбранных продуктов» и «Можно добавить 1–2 продукта»;
- фильтры времени и сложности;
- локальное ранжирование рецептов;
- карточка рецепта, замены, техника и безопасность;
- пошаговое приготовление, необязательный таймер, избранное и история;
- два потока обратной связи: фактическое приготовление клиентом и ручная проверка приложения;
- редакционные статусы `draft`, `reviewed`, `cooked`, `approved`;
- 10 рецептов партии B1 в статусе `reviewed`, 13 рецептов в статусе `draft`.

## Открытая публичная бета

Сборка 3.0-preview.5 переведена из закрытого тестирования в открытую публичную бету. Ссылка может распространяться публично. Обратная связь больше не привязана к WhatsApp: на поддерживаемых устройствах используется системное меню «Поделиться», а на компьютере — копирование текста отзыва.

## Что изменено в 3.0-preview.5

Изменения основаны на пользовательской обратной связи после предыдущей сборки.


### Поиск и ввод порций

- поиск ранжирует совпадения по первым буквам и синонимам;
- Enter или кнопка «Добавить» выбирают единственный найденный продукт;
- ввод двухзначного количества порций больше не переписывается после первой цифры;
- добавлены кнопки −/+ и явное предупреждение для значений вне диапазона 1–20.

### Больше вариантов

- снято искусственное ограничение в три подходящих рецепта;
- сначала показываются шесть лучших вариантов, остальные открываются кнопкой «Показать ещё»;
- строгий режим больше не показывает близкие варианты, требующие докупки обязательных продуктов.

### Обновление PWA

- онлайн-запросы используют network-first, поэтому новая версия не должна оставаться скрытой старым cache-first кэшем;
- файлы приложения получают версионные URL.

### Порции

- вместо списка 1–6 используется крупный бегунок **1–20**;
- рядом есть ручной числовой ввод;
- оба элемента синхронизированы;
- выбранное число порций сохраняется на устройстве;
- количества ингредиентов пересчитываются с бытовым округлением: граммы и миллилитры без десятых, ложки с шагом ¼, штучные продукты без бессмысленных десятичных дробей.

### Подбор

- гибкий режим действительно допускает 1–2 недостающие обязательные позиции, если у пользователя уже есть хотя бы один основной продукт рецепта;
- если точного совпадения нет, приложение показывает до двух **близких вариантов** и прямо пишет, чего не хватает или сколько дополнительного времени понадобится;
- пользователь больше не должен последовательно подстраивать свои параметры под скрытые требования рецепта.

### Состояние формы

На устройстве сохраняются:

- лимит времени;
- количество порций;
- сложность;
- режим подбора;
- выбранная категория продуктов.

### Поиск продуктов

- добавлена кнопка `×` для очистки поиска;
- после выбора найденного продукта поисковая строка очищается автоматически.

### Инструкции

Для рецептов с расплывчатыми формулировками добавлены конкретные формы и приблизительные размеры нарезки: кубики, полукольца, соломка, пластинки и т. п.

### Интерфейс

Главный экран перестроен вокруг трёх последовательных этапов: продукты → параметры → режим подбора. Точные и близкие варианты визуально разделены. Таймер сохранён, но обозначен как необязательный.

## Зафиксированные ограничения

- дополнительных денежных расходов — 0 сомов;
- внешние AI API в приложении не используются;
- регистрация, сервер и облачная база отсутствуют;
- персональные данные и история не передаются на сервер;
- существующие рецепты остаются тестовой контентной основой до фактической кулинарной проверки;
- изображения способов нарезки остаются в backlog и не блокируют preview.5.

## Проверка

```bash
node quality-check.mjs
```

Дополнительно вручную проверить значения порций 1, 5, 7, 12 и 20, сохранение 60 минут после возврата к форме, автоочистку поиска и выдачу flexible-mode при 1–2 недостающих позициях.

## Локальный запуск

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.
