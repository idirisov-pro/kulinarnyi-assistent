# Кулинарный ассистент — версия 3.0-preview.3

Третий рабочий инкремент версии 3.0. Создан без сервера, платных API и привлечения платных специалистов.

## Что перенесено без изменения согласованной логики

- выбор продуктов из нескольких категорий;
- режимы «Только из выбранных продуктов» и «Можно добавить 1–2 продукта»;
- фильтры времени, порций и сложности;
- локальное ранжирование и выдача до трёх рецептов;
- объяснение результата и диагностика пустой выдачи;
- карточка рецепта, масштабирование порций, замены, техника и безопасность;
- пошаговое приготовление, таймеры, избранное и WhatsApp-отчёт;
- работа PWA без сети после первого открытия.

## Сохранено из 3.0-preview.1

- «Моя кухня»: выбранные, исключённые и базовые продукты автоматически сохраняются только на устройстве;
- видимая история последних подборов, открытых рецептов и завершённых приготовлений;
- безопасная очистка истории с подтверждением;
- индикатор прогресса в пошаговом режиме;
- обновлённая версия PWA-кэша.

## Сохранено из 3.0-preview.2

- у каждого из 23 рецептов появились обязательные редакционные поля: ID, версия и статус;
- поддержаны статусы `draft`, `reviewed`, `cooked`, `approved`;
- первые 10 рецептов получили статус `reviewed` и включены в партию фактической проверки `B1`;
- остальные 13 рецептов сохранены в статусе `draft`;
- статус и его понятное объяснение отображаются в результатах и карточке рецепта;
- статус `reviewed` прямо отделён от фактического приготовления и утверждения;
- статусы `draft`, `reviewed`, `cooked`, `approved` и партия B1 сохранены без искусственного повышения статусов.

## Добавлено в 3.0-preview.3

- фактическое приготовление передано клиентам приложения;
- ручная функциональная проверка передана ранее привлечённым тестовым контактам;
- в интерфейсе разведены клиентский отзыв после приготовления и ручная проверка приложения;
- WhatsApp-сообщения явно указывают тип проверки;
- подготовлены два отдельных текста приглашения: для клиентов и для тестировщиков;
- PWA-кэш обновлён до preview.3.

## Зафиксированные ограничения

- дополнительных денежных расходов — 0 сомов;
- внешние AI API в приложении не используются;
- регистрация, сервер и облачная база отсутствуют;
- персональные данные и история не передаются на сервер;
- существующие рецепты остаются тестовой контентной основой до фактической кулинарной проверки.

## Следующий инкремент

1. Клиенты готовят блюда и отправляют структурированный отзыв из приложения.
2. Тестовые контакты выполняют ручные контрольные сценарии на телефоне без обязательного приготовления.
3. Отзывы заносятся в единый журнал и разделяются по типу проверки.
4. После анализа корректируются количества, время, шаги, признаки готовности и интерфейс.
5. Статус `cooked` присваивается только после подтверждённого клиентского приготовления; `approved` — после анализа, необходимых правок и повторной проверки.

## Локальный запуск

Откройте папку через локальный web-сервер. Например, при установленном Python:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.
