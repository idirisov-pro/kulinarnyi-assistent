# Кулинарный ассистент — версия 2

Статическое браузерное приложение без сервера, базы данных и платных API.

## Быстрый запуск на Windows

1. Распакуйте архив.
2. Дважды нажмите `start_local.bat`.
3. Откройте `http://localhost:8080`, если браузер не открылся автоматически.
4. Чтобы остановить локальный сервер, закройте чёрное окно или нажмите в нём `Ctrl+C`.

## Что изменено

- убраны внутренние надписи `ZERO-CASH MVP` и `ПРОВЕРЯЕМАЯ ДЕМО-РЕЦЕПТУРА`;
- убрано дублирующее название в шапке;
- слово «сервис» заменено на «кулинарный ассистент»;
- ингредиенты разделены по категориям;
- добавлены говядина, баранина, виды фарша, творог, варёная колбаса, сливочное, растительное и оливковое масло;
- базовые продукты вынесены в отдельный блок;
- добавлен режим «только из выбранного» и режим «можно добавить 1–2 продукта»;
- вместо абстрактного процента показывается понятный статус;
- отсутствующие позиции разделены на обязательные и рекомендуемые;
- исправлена кнопка отмены формы обратной связи;
- добавлена блокировка выключения экрана в режиме готовки, когда браузер это поддерживает;
- улучшен PWA-кэш и добавлены иконки;
- добавлен автоматический валидатор данных.

## Важно

Рецепты являются рабочей контентной основой и должны пройти фактическое приготовление и редакционную проверку до публичной рассылки.

## Проверка данных

При установленном Node.js выполните в папке проекта:

```bash
node scripts/validate-data.js
```
