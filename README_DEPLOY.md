# Публикация предварительной версии 3.0

Версия: **3.0-preview.3**

## Что проверяется в этой сборке

- сохранение «Моей кухни» после перезагрузки;
- история подборов и приготовлений;
- прогресс пошагового приготовления и клиентский отзыв о готовом блюде;
- отдельный отзыв для ручной проверки приложения;
- сохранение работоспособности подбора из версии 2.1.1-alpha.

Этот каталог содержит только публичные файлы приложения. Рабочую документацию, таблицы, персональные данные и отзывы сюда не загружать.

## Бесплатная публикация через GitHub Pages

1. Используйте подтверждённый репозиторий кулинарного ассистента или создайте отдельный публичный репозиторий `kulinarnyi-assistent-v3-preview`.
2. Загрузите в корень репозитория всё содержимое этого каталога.
3. Откройте `Settings → Pages`.
4. Выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/(root)`.
6. Нажмите `Save`.
7. После публикации GitHub покажет точный адрес страницы. Не рассылайте предполагаемую ссылку до ручной проверки.

## Перед рассылкой

- Откройте ссылку на компьютере и телефоне.
- Выполните один подбор.
- Проверьте кнопку `Отзыв`.
- Перезагрузите страницу и проверьте, что выбранные продукты сохранились.
- Откройте `История` и проверьте появление нового подбора.
- Проверьте пустую выдачу и объяснение причин.
- Не загружайте в публичный репозиторий номера телефонов, таблицы тестировщиков и личные сообщения.
