# Публикация предварительной версии 3.0

Версия: **3.0-preview.5**

## Что проверяется в этой сборке

- бегунок и ручной ввод 1–20 порций;
- бытовое округление пересчитанных ингредиентов;
- сохранение времени, порций, сложности и режима подбора;
- поиск по первым буквам/синонимам, Enter и кнопка «Добавить»;
- flexible-mode при 1–2 недостающих позициях;
- расширенная выдача с кнопкой «Показать ещё» и логически строгий режим;
- конкретизированные инструкции по нарезке;
- обновлённые мобильные контролы порций и поиска;
- network-first обновление PWA вместо удержания старой версии;
- сохранение истории, избранного, пошагового режима и двух потоков обратной связи.

Этот каталог содержит только публичные файлы приложения. Персональные данные, номера телефонов, клиентские сообщения и рабочие таблицы сюда не загружать.

## GitHub Pages

Репозиторий: `idirisov-pro/kulinarnyi-assistent`.

После объединения проверенного PR в `main` GitHub Pages должен опубликовать корень ветки `main`.

## Перед рассылкой

1. Дождаться успешного `quality-check` в PR.
2. Объединить PR в `main`.
3. Дождаться успешного Pages deployment.
4. Открыть страницу на компьютере и телефоне.
5. Проверить порции 5, 7, 14 и 20 через ручной ввод, бегунок и кнопки −/+: не должно быть значений вида `575,3 г` или `1,3 ч. л.`.
6. Выбрать 60 минут, перейти в результаты, вернуться — должно остаться 60 минут.
7. Ввести `кар`, `том`, `овся`, `бедра` и `фарш`; проверить ранжирование, Enter/«Добавить» и автоочистку после выбора.
8. В flexible-mode проверить рецепт с 1–2 недостающими продуктами: карточка должна показываться с явным списком добавлений.
9. При большом числе совпадений проверить первые 6 карточек и кнопку «Показать ещё»; в строгом режиме не должно быть обязательной докупки.
10. Проверить WhatsApp-отзыв: версия должна быть `3.0-preview.5`.
